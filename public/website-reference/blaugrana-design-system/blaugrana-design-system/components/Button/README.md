Pill-shaped action button, the site's `.btn`: label-m (16px / 500, −0.16px tracking) on `radius-full`.

- **primary** – `primary` / `on-primary`. Brand blue on light; flips to white with navy text in the dark (matchday) theme. One per view region.
- **secondary** – `secondary` (gold) with `on-secondary` ink. Commerce: tickets, shop, membership.
- **tertiary** – `tertiary` grey. Quiet actions next to a primary.
- **outline** – 1px `outline-strong` stroke. "See all", filters.
- **grana** – `brand-grana`. Matchday / live moments only, never next to a gold button.

Sizes `s` (32px), `m` (40px), `l` (48px). Pass `href` to render a link. Focus: 2px `focus-ring` outline. Labels are sentence case; the legacy UPPERCASE `.button` is retired.
