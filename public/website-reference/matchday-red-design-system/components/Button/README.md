# Button
Square-shouldered, uppercase condensed buttons used for every call to action ("Buy tickets", "Join Today", "Match Centre").

- **Primary** (`mr-btn mr-btn--primary`): `red-500` fill, `on-red` text; one per card or hero.
- **Secondary** (`mr-btn mr-btn--secondary`): 2px `ink` outline; for the second action ("Match Report").
- **Gold** (`mr-btn mr-btn--gold`): `gold-400` with black text; reserved for premium/upgrade ("Upgrade to Watch").
- Labels are short verbs, 1–3 words. Radius `radius-sm`; padding `space-3`/`space-6`; focus ring `focus`.
- Consumer provides: the label and the element (`<button>` or `<a>`).
