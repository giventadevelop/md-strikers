# MatchCard
Result or fixture summary used in the Matches tab widget: competition header, teams, score, and two actions.

- Header on `black`, `label` style in `on-red`: competition left, date right.
- Score in `display-l`; "FT" / kick-off time in `meta`, `ink-muted`.
- Actions: secondary "Match Report" + primary "Match Centre".
- Body on `surface-200`. Consumer provides: teams, crests (optional), score or time, links.
